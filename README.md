# StudySpark 🚀

**Tagline:** Turn your study mood into your learning method.

StudySpark is a student-focused learning website designed to make studying more engaging by adapting the learning experience to a student's selected mood, subject, topic, and available time.

## 🎯 Problem Statement
Students may feel bored, confused, or low on energy while studying. A single learning method may not work equally well for everyone.

## 💡 Our Solution
StudySpark offers a mood-based learning experience with personalized study plans and activities based on the student's selected mood.

## ✨ Features
- Mood selection: Bored, Confused, Low Energy, Curious, and Want a Challenge.
- Subject, topic, and study-time selection.
- Personalized study plans and learning activities.
- Quick learning challenges and practice activities.
- Student-friendly interface.

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript
